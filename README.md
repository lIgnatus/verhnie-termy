# Верхние Термы

Прототип сайта школы развития сельских территорий в Верхних Термах (Чишминский район, Башкортостан): 3D-модель участка и окрестностей до мавзолея Тура-хана и облако смыслов с графом связей.

Сайт: https://lignatus.github.io/verhnie-termy/

## Как собрать

```
npm ci
node tools/build.mjs
node tools/serve.mjs
```

Сборка ложится в `dist`, сервер открывает её на http://localhost:4180. Пуш в `main` сам собирает и публикует сайт.

## Где что править

- Тексты, смыслы, связи, карточки объектов и помещений: `src/content.js`.
- План участка: граница, сад, домики, дорожки, дренаж: `src/plan.js`.
- Школа: `src/world/school.js`, участок: `src/world/plot.js`, арт-поле и Тура-хан: `src/world/places.js`.

## Данные
